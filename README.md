Esta pequeno proyecto fue desarrollado en respuesta
a una actividad institucional

La actividad es crear un progressbar simulando una carrera de caballo

En respuesta a estos se desarrollo cuatro progressbar que al correr en programo se 
se mueven de forma aleatoria y aumentan su porcentaje, al momento de que algunao de competidores
"caballos", complete el 100% osea gane la carrera aparecera una alerta indicando el ganador, en 
esta se permite reiniciar y acaptar el resultado.
